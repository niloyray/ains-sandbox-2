# Implementation Plan: Health check script: print ok and exit 0

**Jira**: AINSSB2-1 | **Spec**: specs/AINSSB2-1/spec.md

## Summary

Add a stdlib-only `scripts/healthcheck.py` that prints `ok\n` and exits 0, a subprocess-based pytest test, a minimal `pyproject.toml` (pytest as only dev dependency), and a README "Health check" section.

## Technical Context

- Language: Python, floor `>=3.10` (spec default; no CI Python pin found in the repo).
- Dependencies: none at runtime; dev group `pytest` only. Ruff is run via `uvx`, never declared.
- Testing: `uv run pytest`; lint: `uvx ruff check .`.
- Project type: single script; no importable package, no `app/` directory needed.
- Constitution: `.specify/memory/constitution.md` is an unfilled template, so no gates apply. CLAUDE.md boundaries are respected (no edits to `.github/`, `.specify/`, `.claude/`, `CLAUDE.md`).

## Design

### scripts/healthcheck.py
- `main() -> int` writes `ok\n` to `sys.stdout` and returns 0.
- `if __name__ == "__main__": sys.exit(main())`.
- No arguments, no environment reads, nothing written to stderr.
- No `scripts/__init__.py`; the script is run by path only.

### tests/test_healthcheck.py
- Resolve the script path from `Path(__file__)`, so it does not depend on the working directory.
- Run it with `subprocess.run([sys.executable, str(script)], capture_output=True, text=True)`.
- Test 1: run from the repo root and assert stdout == `"ok\n"`, stderr == `""`, returncode == 0.
- Test 2: run with `cwd=tmp_path` (a different directory) and assert the same.

### pyproject.toml
- `[project]`: name `ains-sandbox-2`, version `0.1.0`, `requires-python = ">=3.10"`, `dependencies = []`.
- `[dependency-groups] dev = ["pytest"]`, which `uv run` installs by default.
- No `[build-system]`. This keeps the project a non-package, so `uv run` does not try to build or install it, and there is no publishing.
- `[tool.pytest.ini_options] testpaths = ["tests"]`.

### README.md
- Append a "## Health check" section with the command `python scripts/healthcheck.py`, the expected output `ok`, and exit code 0.

## Risks

- `uv run pytest` needs `pyproject.toml` to parse correctly and resolve pytest, which may need network access in CI.
- A `uv.lock` may be generated by `uv run`. Decide whether to commit it (it is not a dependency declaration); the plan allows committing it as an incidental artifact.
- `uvx ruff check .` scans the whole repo, so the new files must be lint-clean.
- Python 3.10 compatibility: keep the syntax conservative.

## Out of scope
Per spec: real checks, flags, CI/Docker wiring, ruff as a dependency, packaging.
